## Reflection

## 1. Is the TDD flow is useful enough for you or not? If not, explain things that you need to do next time.  
I find the Test-Driven Development (TDD) workflow quite useful because it makes think about the 
expected behavior of the code before implementing it. Writing tests first helps clarify the requirements and 
makes it easier to detect errors earlier. It also helps me structure my code better and ensures that each 
feature works as intended. In the future, I need to spend more time identifying edge cases and writing additional 
tests to improve the reliability of my code.  

## 2. Have your tests successfully followed F.I.R.S.T. principle or not?  
Overall, the unit tests have mostly followed the F.I.R.S.T. principles, 
especially in terms of being Fast and Repeatable since they can run quickly 
and produce consistent results. The tests are also Independent because each test focuses on a specific behavior. However, some tests could 
be improved to be more Self-validating and Thorough by making the assertions 
clearer and covering more possible scenarios.
